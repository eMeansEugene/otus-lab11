Detailed Description

Асинхронный TCP-сервер: принимает соединения и порождает сессии.

На каждое входящее подключение создаёт Session (во владении самой сессии через shared_ptr) и передаёт ей общую базу данных. Слушает на всех интерфейсах (tcp::v4()).
